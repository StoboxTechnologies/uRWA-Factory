# Support

## What is supported

| | |
|---|---|
| **Tagged releases** | Bugs triaged and fixed |
| **`main` branch** | Not supported — it moves |
| **Forks** | Not supported |
| **Deployment configuration** | Not supported here — see commercial support |

## Response times

Issues are read. **No response time is promised.** This is a source release, not a managed
open-source project.

## Where to go

| Need | Where |
|---|---|
| Bug in a tagged release | GitHub issue, with a reproduction |
| Security vulnerability | **Not** a public issue — see [SECURITY.md](SECURITY.md) |
| "How do I configure my offering?" | Commercial support, via Stobox Compass |
| Integration help for an exchange or custodian | Commercial |
| Methodology or roadmap disagreement | A pull request or a fork; both are legitimate |

## Commercial support

Stobox Compass provides configuration, hosted issuance, the Asset Passport attestation service, and
support with agreed response times. That is a separate commercial arrangement and is not required to
use this software.
