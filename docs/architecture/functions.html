Orbit Functions

Every principal function of Stobox Orbit, module by module: what exists in src/ today, what changes, what is new. Read from the code on 25.09.2026 – 145 public functions across 13 contracts – and from the five design pages. The status is the function's, not the module's: a module can be "ready" and still carry one function that must change.
